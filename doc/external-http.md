# 外部フィードの取得先検証

RSS/AtomおよびFlickrのHTTP(S)接続では、接続直前に名前解決したすべてのIPが
公開アドレスであることを検査し、検査した数値IPへ直接接続します。
ホスト名を再度名前解決せず、DNS rebindingによる内部ネットワークへの接続を防ぎます。
リダイレクト先にも同じ検査を適用します。HTTPSのSNIと証明書検証には元のホスト名を使います。

環境変数のHTTP_PROXY/HTTPS_PROXYは、この外部取得用クライアントでは使用しません。
汎用プロキシが接続先を再解決するとIP検査を保証できないためです。
直接の外向き接続が必要です。プロキシ必須の環境では外部連携が失敗する場合があります。
その場合は同等の宛先制限を持つ信頼できるプロキシへの対応を別途実装してください。
証明書検証や接続先の検査を無効にして回避しないでください。
