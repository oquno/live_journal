# 管理者セッション

ログインごとにランダムなトークンを発行し、ハッシュと有効期限をSQLiteに保存します。
有効期限は発行から12時間です。ログアウトすると対象トークンを削除し、コピー済みの
Cookieも再利用できなくなります。複数のGunicornワーカーで同じ失効状態を共有します。

管理者名・パスワード・署名キーが変わると、次のセッション発行または検証時に既存の
セッションをすべて削除します。環境変数を変更した場合は全ワーカーを再起動してください。
異なる認証設定のワーカーを同時に稼働させないでください。

更新時は起動処理でテーブルが自動作成されます。以前の署名Cookieは受け付けないため、
導入後は再ログインが必要です。期限切れのセッションは次の発行時に削除します。
