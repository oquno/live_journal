# ログイン試行の制限

`POST /login` は接続元ごとに5分間で10回まで受け付けます。成功したログインも
回数に含め、超過時は `429` と `Retry-After` を返します。SQLiteに記録するため、
Gunicornの複数ワーカーや再起動でも制限が共有されます。期限切れ記録は次の試行時に削除します。

接続元にはWSGIの `REMOTE_ADDR` を使用し、クライアントが偽装できる
`X-Forwarded-For` は信用しません。リバースプロキシ経由ではプロキシを同一接続元として
扱います。単一管理者の利用を想定した保守的な動作です。多数の利用者を扱う場合は
信頼するプロキシで送信元別の制限を追加してください。分散した送信元による試行を
完全に防ぐものではありません。
